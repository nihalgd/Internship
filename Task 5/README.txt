TASK 5 - FULL CAPSTONE PROJECT
SwiftCart is a responsive e-commerce frontend.

Features:
- Product search, category filtering and price/rating sorting
- Dynamic product cards
- Add/remove cart and total calculation
- Responsive desktop/tablet/mobile layouts
- Vanilla HTML/CSS/JavaScript, no external libraries
- Semantic structure and accessible controls
- No external images or framework requests, reducing HTTP requests

Run by opening index.html or using VS Code Live Server.
Test Chrome, Firefox and Safari/mobile browser widths.
